## Local workflow
1. Create a branch: `git checkout -b feature/assignment5`
2. Edit `src/calc.cpp`.
3. Run tests: `cmake --build build && ctest --test-dir build`
4. Push and open a PR: `gh pr create`
5. Grade: `python scripts/grade.py assignment5 <pr_number>`
